# Spring Mesh Bloom

A cyberpunk spring-mass mesh that settles into a floral bloom under gravity.

## Open
Open `index.html` in any modern browser (works from `file://`).

## Features
- Drag any node to stretch the springs
- Gravity slider (0–3)
- Damping toggle
- Export current bloom as PNG

## Notes
Canvas 2D + Verlet integration. System fonts only, no dependencies.
