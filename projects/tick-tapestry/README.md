# Tick Tapestry

A canvas where each second paints a new colored thread, weaving time into a living tapestry.

## Open
Open `index.html` in any modern browser (works from `file://`). No build, no dependencies.

## Controls
- Speed slider: threads per second
- Palette: 4 grunge palettes (3 colors each)
- Pause / Resume, Rewind (replays the weave), Reset
- Export GIF: downloads a looping GIF of the weave

Threads persist in localStorage.
