# Iris Molecule Inn

> A pixel-art social inn: check in as a molecule, leave a note on the wall, share the guestbook.

Visitors pick a molecule shape and color, write a short note, and appear on a shared wall.
Everything persists in the browser; export the wall as PNG or copy a share link that
restores the exact guest list.

## Run

Open `index.html` in any modern browser (works from `file://` and static hosts).

## Features

- **Check in** — name, note, molecule shape, color.
- **Wall** — pixel cards with molecule avatars; remove your own entries.
- **Share/export** — copy a share link (encoded in the URL) or download the wall as PNG.

## Constraints honored

- Static HTML/CSS/JS, no build, no npm.
- 3 palette colors plus black/white; system fonts only (no external fonts).
