# Dulse Otter Outpost 🦦

Otters run a seaweed trading outpost. Harvest kelp, trade the tides, build your crew, grow your renown to **Living Reef (1,500)**.

## How to open
- Double-click `index.html` (works from `file://`), or serve statically: `python3 -m http.server` in this folder → open the URL.
- No build, no npm, no keys. Saves to `localStorage`.

## What it does
- **Kelp trade** — 3 kelps (Dulse Ribbon, Sugar Kelp, Oarweed) with prices that drift every tide; buy low, sell high.
- **Otter crew** — hire 5 otters, each with a passive perk (sell bonus, harvest yield, tide income, buy discount, score bonus).
- **Outpost score** — renown = clams + stock value + crew + trades; ranks from Driftwood → Living Reef with a progress bar + chronicle log.

## Easter egg 🥚
Pet the sleeping otter in the header (or the moon) **5 times**, or type `kelp` — the **Golden Otter** wakes: +150 clams, a free golden captain, confetti. Try it.
