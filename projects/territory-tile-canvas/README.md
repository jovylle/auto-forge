# Territory Tile Canvas

Paint grid territories by hand and watch borders bloom across a tiny living fantasy map.

## Open
Open `index.html` in any modern browser (works from `file://` and static hosts). No build, no dependencies.

## Features
- **Draw territory tiles by hand** — pick a territory color and drag across the grid.
- **Auto-fill neighboring regions** — use the fill (bucket) tool to flood a connected region at once.
- **Export map as PNG** — renders the current map (grid overlay follows the toggle).
- **Toggle grid overlay** — show/hide the tile grid.
- Scroll to zoom; drag empty space to pan.

Progress saves to localStorage.
