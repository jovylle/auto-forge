# Gravity Spring Playground

A tiny sandbox where particles orbit, spring, and fall under tunable gravity.

## Open
Open `index.html` in any modern browser (works from `file://`).

## Features
- Drag on the canvas to spawn a particle (drag direction sets velocity).
- Adjust gravity, spring stiffness, and damping with the sliders.
- Toggle the live force-vector overlay (gravity, spring, net).
- Export a short animated GIF of the scene.

## Controls
- **Burst** spawns 30 particles in a ring.
- **Clear** removes all particles.
- Spring anchor: center / top / bottom.
