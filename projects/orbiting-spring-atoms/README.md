# Orbiting Spring Atoms

A sci-fi terminal visualization: particles connected by springs orbiting a gravity well.

## Features

- Adjust gravity (slider)
- Drag particle-to-particle to add springs
- Particle trails with adjustable length
- Pause / resume and reset
- Spring stiffness control
- Clear all springs
- WebAudio interaction sounds (no assets)

## Run

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Controls

- Drag from one particle to another to create a spring
- Sliders: gravity, trail length, spring stiffness
- Buttons: pause/resume, reset, clear springs
- Keys: Space = pause, R = reset
