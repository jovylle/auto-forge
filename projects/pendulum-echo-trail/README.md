# Pendulum Echo Trail

A pendulum whose fading echoes paint time's passage across the canvas.
Japanese-cyberpunk generative piece: the swing leaves a neon trail that
fades over 30 seconds, and the trail hue shifts with the current hour.

## Open
Open `index.html` in any modern browser (works from `file://`).

## Controls
- **PAUSE / PLAY** (or Space) — stop and resume time
- **REWIND** (or R) — reset time to 0 and clear the trail
- **SPEED** — 0.5× to 4×
- **SCRUB** — jump to a time (pauses playback)
- **EXPORT PNG** (or E) — download the current canvas as PNG
