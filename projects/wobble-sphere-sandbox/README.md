# Wobble Sphere Sandbox

A tiny physics toy — spheres bounce, spring, and settle under gravity. No build, no deps, works from `file://`.

## How to open
Open `index.html` in any browser (or serve statically). Works at 375px width; touch supported.

## What it does
- **Drag to launch spheres** — pull back from a point, release to fling; tap to drop a resting sphere.
- **Adjust gravity and spring stiffness** — sliders in the header.
- **Trail visualization** — toggle trails on/off.
- **Reset with one tap** — Reset button clears all spheres.

## Controls
- Drag on canvas → aim/launch; tap → drop sphere.
- Sliders: Gravity, Spring. Checkbox: Trails. Button: Reset.
