# Elastic Marble Garden

Launch elastic particles into a gravity well and watch springy collisions bloom across the canvas.

## Open
Open `index.html` in any modern browser (double-click or serve statically). No build step, no dependencies.

## Controls
- Drag on the canvas to sling a marble (direction = opposite drag).
- Gravity slider: strength of the central well.
- Springs toggle: connect nearby marbles with elastic springs.
- Color by velocity toggle: hue tracks speed.
- Sound toggle: WebAudio clicks on launch/collision.
- Clear: remove all marbles.
- Export GIF: records ~3s and downloads an animated GIF.

## Notes
