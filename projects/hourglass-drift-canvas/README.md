# Hourglass Drift Canvas

Watch sand flow and rebuild shapes as time runs out.

## Open
Open `index.html` in any modern browser (Chrome/Edge/Safari/Firefox). No build, no server required; also works from a static host.

## What it does
- Flowing sand simulation inside a glass hourglass (canvas particles with collision + piling).
- A countdown timer auto-triggers shape morphing; sand rebuilds into the next shape (circle, triangle, square, star, heart).
- Auto-reset loop: after morphing, sand scatters and flows again.
- Three color themes (Amber Dune, Aurora Ice, Ember Mono) — persisted in localStorage.
- Pause / Reset controls. Responsive down to 375px.

## Constraints
- 3 accent colors max (plus black/white). Glassmorphism aesthetic.
